# Dify Setup

Add Inferflow as an OpenAI-compatible provider in Dify.

```text
Provider type: OpenAI-compatible
Base URL: https://api.inferflow.dev/v1
API Key: your Inferflow API key
Model: deepseek-v4-flash
Doubao model: doubao-seed-2.0-mini
```

Use `/v1/models` or the Inferflow Models page to confirm model aliases available to your account.
