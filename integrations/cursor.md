# Cursor Setup

Use Cursor's OpenAI-compatible provider settings.

```text
API Key: your Inferflow API key
Base URL: https://api.inferflow.dev/v1
Model: deepseek-v4-flash
Advanced model: deepseek-v4-pro
Doubao test model: doubao-seed-2.0-mini
```

If named models are unavailable in your Cursor plan, switch the client model mode to Auto or use another OpenAI-compatible client for verification.
